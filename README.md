# Snapglass beta

Snapglass is a menu-bar screenshot and screen-recording app for **Apple silicon Macs running macOS 14 or later**.

## Downloads

[Browse numbered beta releases](https://github.com/elenaOnline/snapglass-releases/releases).

The first signed, notarized beta is being prepared. Download a numbered release when one appears; the `beta` release contains only the update feed.

## Install and update

1. Download the DMG from a numbered release and drag Snapglass into Applications.
2. Open Snapglass, grant Screen Recording in System Settings → Privacy & Security, then quit and reopen it.
3. Enable Microphone, Accessibility or Input Monitoring only for the features you want to use. Preferences → About explains each permission.
4. For future versions, choose Preferences → About → Check for updates, then Download and install. Save your work and quit/reopen when ready; updates never force a restart.

## Beta limitations

The first beta's bundled tldraw editor evaluation licence expires **October 3, 2026**. Annotation editing needs a newer valid licence after that date. Capture and recording are separate from the editor licence. Read each release's notes before installing.

Captures and history stay on your Mac. Update checks contact GitHub only when requested. The tldraw evaluation/watermark licensing logic contacts its CDN. There are no Snapglass accounts or capture uploads.

[Report a bug](https://github.com/elenaOnline/snapglass-releases/issues). Include the app version, macOS version and steps to reproduce. Omit private screenshots, recordings, logs or licence keys.

This repository contains release downloads and the update feed. Application source is maintained separately. Beta availability does not imply Mac App Store approval.
